## 扩充案例的检索边界

- **廉颇与蔺相如**：适用于有共同任务、职位或贡献评价冲突且沟通仍有安全空间的情境。《史记》单源中的和解不能推出面对威胁时总该忍让；舍人的不满也是结果的一部分。
- **陈平受任**：适用于分开核查岗位能力、具体指控与授权风险。《史记》《汉书》措辞相近，不作独立双证；指控与自辩都不是调查结论，后续有贡献也不证明旧指控虚假。
- **田丰劝久持**：田丰先劝趁曹操东征袭后，后劝久持，不可概括为始终等待；官渡败局不证明未实施方案必胜。
- **固陵会兵**：用于讨论多方合作未按约到位、条件变化与承诺可兑现性。《史记》卷七、卷八同书互参；张良对未至原因的解释不是韩信、彭越的自述，会兵也不证明封地承诺已履行。

后四例的决策者、约束与结果指标不同；没有足够的共同指标，本轮不新增正式对照卡。

## 正式对照的共同结构与限制

这两例的正式对照为 comparison_exit_response，由 SKILL.md 直接链接。对照首先询问用户下一阶段想要什么，再分析动作、条件与未来影响；可比性为 limited，不是已经证明机制的成败实验。两例原有结果标签采用的指标不同，必须阅读对照卡的共同指标，不能直接把 success 与 failure 当作一成一败的因果证明。

- 《史记》记范蠡实际离去，文种收到劝离信后称病不朝，后来遭赐剑。不能把后者改写为完全没有回应。
- 两人的资源、退出条件、与勾践的关系等并未充分记录，不能据最终结局认定只差“舍不舍得权位”。
- 《国语》记范蠡离去而去向不明；《史记》给出后续经历。这是叙述范围及细节的差异，不可把缺载当成反证，也不可拼成全部可靠的唯一传记。
- 新增《吴越春秋》的内忧与怨望指控叙述，分别标作较晚心理归属及他人指控，不把细节丰富当作更可靠。缺席程序、真实病情和全部备选仍未知。
- 同一部《史记》的不同网站页面只提供录文对照，不能计算为多份独立史料；《国语》与《史记》的材料关系也未在此次考证中确定。
- 不把对勾践外貌的描写当作人格证据，不将一般领导或合作伙伴直接比作会杀功臣的君主。

## 从案例引出的现实核查

先按目标澄清指南确定用户希望这一阶段生活怎样变化；不知道时用具体经历与小体验引导，不急于推荐去留。目标清楚后，根据当前问题选择少量必要问题，不机械全问：

1. 目前的担忧来自哪些可核验行为，而非由故事激起的猜测？
2. 减少参与后，哪些责任、权限、依赖或风险仍然存在？
3. 退出的资源、时间、履约与接续安排是什么？有哪些替代路径？
4. 哪些实际变化意味着应重新评估，而不是因为历史人物的结局立即行动？

将回答连接到路径的日常、中期机会与下一步，不能停在现实清单。这些是现代分析提出的检查项，不是古籍已经验证的管理规律。它们不支持“一有成绩就该退出”“留下必然遭背叛”或“所有上位者都不可信”。
