# 《埃隆·马斯克传》：按顺序改进流程的五步法

## 能解决什么，不能解决什么

当工作流程过繁，团队准备优化或自动化，却没有确定各步骤为何存在时使用。输入是目标、现行流程、各步骤用途与执行权限。安全、质量与义务的要求须有依据地审查，不能因步骤烦琐就擅自删除；本卡不提供裁员或高风险生产操作指令。

## 对话中的用法（本技能改编）

以下步骤、输出格式和例子是本技能改编，不是书中逐字流程。

1. 质疑要求：逐项列用途、约束依据与可询问的负责人；先得到待澄清清单，无权限或依据不足时只提出问题。
2. 删除：在获得授权且可恢复的范围试去除一项无必要的重复步骤；以目标是否仍达成为检验，必要时恢复。
3. 简化优化：对保留部分减少重复输入、交接或复杂度；质量与目标不满足则停止继续提速。
4. 加快周期：找当前瓶颈，记录处理时间与错误变化；若只把负担转给下游，返回前一步。
5. 最后自动化：仅处理已明确且稳定的重复动作，保留观察与退出方式；效果未达标则恢复人工并重查前四步。

## 原创示例与常见误用

**原创示例：**课程项目准备自动整理重复填报内容，先确认提交格式，去除个人笔记中的重复登记，再统一保留字段，测一次完整过程，最后自动化固定格式转换；原资料与必须提交的部分须保留。

**误用、关联与历史类比边界：**误用是删减越多越好、把加速当加班，或用名人成功证明不必测试。历史削减机构、裁军等事件的约束与现代流程不同，不能凭相似口号迁移。本卡与《你的灯亮了吗？》相连：定义问题先于优化。
