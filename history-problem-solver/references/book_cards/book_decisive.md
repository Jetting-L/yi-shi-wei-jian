# 《决断力》：用 WRAP 组织重要选择

## 能解决什么，不能解决什么

当选项被压成二选一、资料明显只支持偏好，或短期情绪挤占长期目标时使用。输入为目标、现实约束、候选选项和期限。低成本日常小选择不必走完整流程；时间或资料不足时明确尚未完成的阶段。

## 对话中的用法（本技能改编）

以下步骤、输出格式和例子是本技能改编，不是书中逐字流程。

1. 确定目标及必须满足的约束，补充至少一个可行替代选项；若只能二选一，解释限制从何而来。
2. 为各选项写出关键假设和一条反证问题，收集能够改变排序的信息；可逆且有条件时先做小范围试探。
3. 分别从当下和稍长时间范围评价得失，用用户核心优先项做比较；换位建议只能辅助，不能取代用户价值。
4. 写下坏情况、好情况以及重新评估信号；在行动期限内形成暂定选择，信号出现时重新检查。

## 原创示例与常见误用

**原创示例：**在退出社团与勉强坚持之间纠结，可补充“缩小职责”“完成本阶段后退出”等现实选项，核对工作量，再按学习、关系和休息的优先级选择；若承诺的减负没有发生就重评。

**误用、关联与历史类比边界：**误用是为了扩大选项制造不可执行方案，或把换位建议当权威答案。参见 [既有 WRAP 卡](../methods/method_wrap.md) 与 [事前验尸卡](../methods/method_premortem.md)。历史案例只用于生成备选与反证问题，不能直接充当现代选择的成功概率。
