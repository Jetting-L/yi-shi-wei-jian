# 历史推理：从时序与过程证据检查解释

状态：**有限本地条件接入**；原编制及来源核读为 2026-10-02，本次登记为 2026-10-06。内容及版本化行为审阅依据见 [V7-R2](../../docs/modern_layer_v7_r2_astra_review_20261005.md) 与 [V8](../../docs/modern_layer_v8_local_astra_review_20261006.md)，本次差异待 Astra 收尾复核。本指南不提高历史主张或证据等级；方法论不是历史因果或现实效果证明。

## 用途与证据边界

当历史解释影响现实建议，或几种原因难以区分时，按需要检查下面的薄弱处。简单史实查询无需展开整套流程。方法论提供核问方式，不直接证明任何历史因果；清楚的叙述、相似的结局和合理的心理故事不能代替过程证据。

Collier 强调描述、时序与有诊断价值的证据，且不同证据检验的意义依赖假说和背景假设；其 2019 补记提醒解释关系并不总是互斥。[HR-S1] Heuer 的所读节段强调同时考虑解释、证据的区分力、关键证据可靠性，以及“未证实”与“已否证”的区别；其中“有效／已证明”等评价是作者表述，本指南不将其当通用干预效果证据。[HR-S2]

以下时间表、解释记录、沉默检查与反事实边界是**本技能改编**，结合既有 [史料规则](../SKILL.md) 和 [历史复查限制](../../docs/history_case_batch_a_astra_recheck_20261001.md)。不导入整套 ACH 评分、Bayesian 计算或正式因果识别算法；未排除的解释不必假装有概率排名。

## 1. 分开三种时间

| 时间 | 记录什么 | 不能混入什么 |
| --- | --- | --- |
| 事件时序 | 提议、批准、实施、反馈、结果分别发生何时；不详就标未知 | 不能将后来实施写成先前已有资源或权限 |
| 当事人可知时点 | 在具体决策窗口，当事人通过什么渠道可能知道什么；史料是否支持收到信息 | 后来结果、后世评论或现代分析者知道的信息 |
| 材料形成时点 | 记录／编纂年代、叙述者位置、引述还是转述、版本与传承限制 | 后世叙述不能自动等于当事人的即时日志 |

先定一个决策窗口，再判断选择；新信息到来可以开启下一窗口，旧判断和旧未知保留。史料未交代收到消息，不因事件已经发生便写“他知道”。例如赵充国讨论留屯的预测与后来留屯加出击的结果分开，不把混合行动结果倒填为纯屯田的已知效果。

## 2. 判断解释是竞争还是兼容

先写清要解释的现象，防止一个解释针对短期行为、另一个针对长期结果却被当作冲突。每种解释记录：机制假说、成立条件、支持材料、预期能观察到的过程、会削弱它的证据、尚缺的材料。

- **竞争解释：**对同一现象作互不兼容的判断，说明冲突在哪一条件或预测；寻找真正能区分它们的信息。
- **兼容解释：**不同因素可能共同作用，如资源压力与政治支持；共同成立不表示贡献大小已知。
- **包含／部分重合：**一个解释可能是另一个的环节，或只解释部分过程；不要把同一环节算作两个独立原因。

这些便于对话的分类借鉴 Collier 补记对解释关系的提醒，不是对 Zaks 原论文的直接核读或完整转译。[HR-S1] 不固定解释数量；只保留能影响判断的解释。共同支持多种解释的证据可以有价值，但不能单凭它优先某一种。[HR-S2]

## 3. 沿过程寻找能改变判断的证据

对“条件 → 行动 → 中间变化 → 结果”的每一连接，说明发生记录、言论归属或分析推断。时间先后本身不能证明机制；声明准备做、获准做、已做、对方收到、长期结果也不是同一事实。

先问：若机制成立，哪一个过程应当留下什么痕迹？现有材料是否出现？痕迹是否也可能由其他解释产生？若关键材料被误记、来源有偏或另有解释，结论怎样变化？必要条件有证据缺失不等于它不存在；有可靠反证才按其范围削弱或排除解释。

Collier 的检验示例说明同一线索的区分力会随背景假设而变，罕见的强排除不能被故事直觉代替。[HR-S1] 本指南只用这些核问，不给史料机械贴四类检验标签或累计分数。最小补证任务应写成“查哪份材料的哪段，以区分哪个解释”；若无法取得，限制结论而非补造证据。

## 4. 来源依赖不能变成多重佐证

为关键主张画简短来源链：原记录／奏文或言论 → 后来编纂 → 当前录文／翻译 → 案例卡。标出已确认的承袭与未知的传承关系。

同书不同篇章、承袭同一原记录的史书、同一 DOCX 及其 Markdown 转录、同一 PDF 的两个副本，都不能仅因文件多而算独立验证。不能确认依赖关系时写“来源独立性未确认”，既不自动合并所有材料，也不自动当作独立。相互独立的材料仍须核对观察对象、口径与利益位置；来源数量不等于机制被确证。此项沿用本技能史料规则，不冒称所读 Heuer 节段验证了这一具体程序。

## 5. 材料沉默需要检验记录机会

“未记载反对／返戍／兑现”只能先表述为“所核材料未记载”。若要让沉默削弱某一解释，至少说明：

1. 假如该行为发生，为什么这类材料通常应记录它？
2. 作者、文体、时间段和保存状况是否覆盖该行为，有没有删节、选择性叙述或记录渠道缺失？
3. 是否实际检索了相关材料，还是只读一个段落？有无其他可能留痕的材料？

记录预期或覆盖不足，沉默就不承担“没有发生”的证明责任。即使条件较好，结论也限于该材料的记录机会，不能扩成全体赞同、未被追索或从未采取其他行动。Heuer 区分未证实与否证，提供避免过早排除的提醒；这里的记录机会检查为技能原创操作。[HR-S2]

## 6. 反事实只作有条件的分析

先分实际提出的选项、实际实施的行动与现代分析者构造的假设选项；用卡片的 availability 与 claim_refs 对照，不把假设写成古人确有选择。

明确改动哪项条件，以及哪些背景仍假设不变；再查权限、资源、时机、实施步骤、其他参与者反应及恢复空间是否可行。不能在删掉一个条件的同时暗中保留依赖它的收益。条件缺口越多，判断越应收窄。

未实施的方案没有可观察结果；失败／成功的实际方案不自动验证另一方案。另一地点、时期或制度中的后续事件只能提出疑问，不能代替同条件检验。反事实可用于发现依赖与补证需要，不据此宣布“必胜”“必败”或精确收益。[HR-S1；本技能边界]

只填当前影响结论的部分。若关键来源失效、时间错位、条件不成立或重要替代解释出现，就重评并保留原记录；无法补证时明确未知，不以形式完整宣布因果已查清。
