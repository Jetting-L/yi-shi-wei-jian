# 目标澄清与路径分析

这是一套对话启发式，不是心理测评，也不声称经实验证明适用于所有人。用于把历史借鉴接到用户下一阶段的生活上。

## 先分辨目标是否已知

| 用户状态 | 本轮任务 | 避免 |
|---|---|---|
| 只提出行动：我要不要辞职？ | 先了解想获得或摆脱什么，提出一至三个问题后等待 | 直接给“先别辞职”的完整方案，再在末尾象征性问目标 |
| 目标清楚：一年积累一笔学费，之后转向创作 | 复述目标并比较能达到它的路径 | 重新问“你到底想要什么人生” |
| 多目标冲突：要自主，也想稳定收入 | 找本阶段优先级、可接受底线和阶段顺序 | 把用户归为安稳型或冒险型 |
| 不知道：只觉得该改变了 | 用具体经历和短期体验探索暂定方向 | 逼其给宏大使命，或无限追问为什么 |
| 不愿回答或只要快速建议 | 说明假设，提供少量条件分支供自行选择 | 擅自补全动机，或以必须回答为由拒绝帮助 |

用户的目标可以变化；目标排序也不保证现实可行。先理解其价值，再诚实检查实现条件。不要用“现实不允许”跳过目标，也不要用“追随内心”跳过约束。

## 第一轮怎样问

优先开放问句，再以例子帮助表达。每轮按能各自回答的独立信息需求计数，最多三个；不按问号、编号或项目符号数量计数。根据用户已给的信息和当前卡点选择问句，未选需求留到后续，不把整组候选一次问完。目标已明确时直接分析路径，不为凑问数重新盘问。

以下是可按需选用的候选问句，每句对应一个独立需求，不是固定问法或必填项：

- “这次改变如果是值得的，你希望下一阶段的日常具体有什么不同？”
- “现在最想保留什么？”
- “现在最想减少什么？”
- “如果这些目标冲突，这一阶段更愿意保护哪一个？”
- “这个阶段你想持续多久？”
- “最不能接受付出的代价是什么？”

例如，“想到答应，哪个画面最让你心动？”和“想到拒绝，哪件事让你松一口气？”是两个独立需求；若本轮采用这个对照，再追问的独立需求最多一个，其余留到后续。

可举例：更多可支配时间、探索或创造、达到一笔收入目标、陪伴家人、恢复精力、专业成长、服务他人。它们可以并存，也可以全不适用。不要把“安稳”和“披荆斩棘”写成带褒贬的二选一。

## 回答“不知道”时怎样推进

从下面选择一个入口，听完回答再决定下一问，不能一次倾倒全部练习：

- 具体生活：请描绘一个愿意重复的普通星期，而非十年后头衔。一天的时间想怎样分配？
- 经历对照：最近哪件事让你愿意继续投入，哪件事希望少一点？不把一次情绪自动当永久偏好。
- 取舍测试：以用户情境提出两种可想象的生活，问更能接受哪一种代价，并允许“都不合适”。
- 小体验：例如试做一小段真实创作、和实际从业者讨论日常工作，或试行一个恢复个人时间的安排。共同约定规模与反馈问题；不擅自设定成本或期限。

一两轮仍不清楚时，共同形成“暂定探索目标”：现在还不选最终方向，先验证自己是否喜欢某种日常、工作内容或责任。下一步必须能带回新信息，不能只有“再想想”。

区分“摆脱当前不适”与“走向下一阶段”：两者都合理，但摆脱后要怎样生活仍可能未知。不要把不满等同于创业愿望，也不要把担忧等同于缺乏勇气。

## 确认一份轻量的阶段目标

用自然语言概括并允许用户纠正，不强制展示表单：

- 时间范围：由用户设定或商议的下一阶段，不是要求一生不变。
- 想增加、减少与保留的体验。
- 当前优先目标及其他仍重要的目标。
- 最低要求与不能接受的代价；由用户确认，不由模型代定。
- 看得见的进展：日常、关系、能力、作品、收入或其他用户认可的信号。
- 未决定之处：哪些价值取舍仍开放，哪些现实信息还不足。

复述示例：“听起来，你这一阶段想先完成一笔明确的储蓄目标，同时保留探索创作的时间；你不是急于成为创业者。我理解得对吗？”若这些内容已由用户明确表达，可直接据此分析，不要求额外确认才能继续。

## 目标明确后的路径比较

按实际可行性选二至四条路径；这些是生成选项的例子，不是固定答案：原岗位协商调整、换同类工作、分阶段验证新方向、全职转向新方向、安排恢复或照料期。

| 需要比较的项 | 必须解释的内容 |
|---|---|
| 与阶段目标的关系 | 这条路径如何帮助或妨碍用户要的生活；不是仅列优缺点 |
| 短期日常 | 时间、精力、现金流、关系和责任会怎样变化；仅分析相关维度 |
| 中期影响 | 可能积累或中断的能力、作品、机会与关系；说明条件 |
| 更远期影响 | 会打开、保留或压缩哪些后续选择；不能断言人生结局 |
| 主要代价 | 用户是否愿意承受，哪些由他人承担，是否与底线冲突 |
| 关键证据 | 还缺什么信息，取得后可能怎样改变排序 |
| 下一步 | 可执行动作、它检验什么、得到什么反馈后继续或调整 |

同一现实条件可能产生不同路径排序：稳定收入可能服务阶段储蓄，也可能占用用户最看重的创作时间；创业可能增加自主决策，也可能带来客户和经营责任，不能把自主等同于随时自由。

中立不是回避判断。若某路径与用户确认的底线明显冲突，应直接指出；若用户愿意承担相应代价，也应公平分析该路径可能带来的价值。建议始终写成可纠正、可调整的判断。

## 对话示例：项目完成后的去留

用户：“项目成功了，领导也表扬我，但我没有下一份工作。是不是应该马上辞职？”

第一轮示范：

“项目成功本身不能决定去留。更关键的是，你希望这一阶段的成果把你带向怎样的生活。接下来一段时间，你最想增加什么、最想保留什么？例如更稳定的日常、尝试自己的项目、先完成一笔收入目标、更多家庭时间，或完全不同的东西，都可以，也可以兼有。是什么让你在这个节点想到辞职？”

随后等待。不要同时给出十条求职准备清单，或抢先定下留任结论。

用户：“不知道，我只是觉得项目结束了，好像该有变化。”

第二轮示范：

“可以先不决定辞职。我们先弄清想改变的内容：回想项目期间，你最想少一点的是哪件事，最希望继续保留的又是哪件事？不必是职业目标，也可以是晚上有自己的时间、完成作品的感觉或与某些人合作。先从这两点描述就够了。”

这里“先不决定”是暂缓形成结论，不是建议长期留任。若用户不愿反思，可直接用几种目标给条件分支。

用户：“想先攒够下一年学习的钱，同时每周留出固定创作时间；不想现在创业。”

下一轮应比较保持岗位但调整任务、换更合适岗位、安排有准备的学习或创作阶段等路径，说明收入目标与时间目标的冲突。下一步可以是估计资金缺口、核实可调整的工作时间，以确定哪条路径更接近这两个目标；不能仍然反复追问人生意义，也不能硬塞创业方案。
