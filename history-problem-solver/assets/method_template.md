# 方法卡模板

用于维护资料，不要求用户按字段填写。标明原方法、应用改编和未证实的主张，保留稳定 ID。

```yaml
schema_version: "0.1"
method_id: method_replace_me
title: 待填写
evidence_type: conceptual_framework # 或 economic_concept / practitioner_tool / adapted_heuristic
review_date: YYYY-MM-DD
source_scope: 已读取的具体范围；不得只写“已核验”
```

## 能解决什么，不能解决什么

写出触发条件、需要的输入、当前不适用情形。明确是否必须先知道用户目标。

## 来源与证据边界

列作者、篇名/章节、链接、阅读范围。用短段落写来源支持的核心概念；不要把作者倡议当成因果效果证据。区分主要来源、概念出处和本技能原创应用。

## 对话中的用法（本技能改编）

写三至五个可执行步骤。每步指出需要的信息、得到什么、何时停止。不要用追问替代推进。

## 最小产出与复盘

提供简短可填句式：目标、行动、观察、复盘或改判条件。阈值来自用户或明确为商议中的例值。

## 原创示例与常见误用

示例连接日常生活、中期发展与未来选择；不要只有收入比较。说明反例、误判来源、适用边界及与历史类比的关系。保持篇幅与实际价值相称。
